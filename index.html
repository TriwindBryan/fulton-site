How it works

Four steps, and the last one is playing.

  1. Add a portOpen Find more and press Add on a game.
  2. InstallFulton downloads and sets it up from the official release.
  3. Add your ROMDrop it on the window, or point Fulton at your ROM folder once.
  4. PlayPress Play. Fulton keeps it updated and backs up your saves.

Questions

Does Fulton include games or ROMs?

No. Fulton comes with no games. You bring ROMs from your own copies, and Fulton downloads the ports from their official GitHub releases.

Is it free?

Yes. Fulton is free, and so are the core features. If you enjoy it you can support it on Ko-fi, which helps pay for things like code signing for Windows and Mac.

Which games work?

Decompilation and recompilation ports, and remakes: native PC versions built from the original game's code. Some need ROM files from your own console, and the label on each card says which. Many ports are Windows-only, and Fulton marks the ones without a Mac or Linux download.

Why does Windows or my Mac warn me?

Fulton isn't code-signed yet, because signing costs money every year. The warnings are expected for now. The steps above get you past them, and the project's code is public on GitHub if you want to look.

Where do my files and saves go?

Fulton keeps everything on your computer. It never moves or deletes your ROM files. Saves are backed up before updates and after you play.

Who makes Fulton?

Fulton is designed, tested and maintained by Triwind, a retro gamer of 40+ years. The code was written with the help of an AI assistant (Claude), and every feature, fix and release is decided and tested by Triwind.

Fulton is free, and it's made by one person

If it saves you time, a Ko-fi donation helps keep it going and pays for signing, so Windows and Mac stop showing warnings.
